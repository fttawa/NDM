Features

为速度而生，也为细节

该有的下载器能力一样不少，界面保持安静、克制。

多连接分段 + 动态分段

每个任务最多 32 条连接，每段独占一条 TCP 连接。连接空闲时自动拆分剩余最多的分段接手，跑到最后也不掉速。

16 个分段0%

连接超频

实测请求延迟，预判即将传完或重试中的连接，提前补上新连接，防止掉速。

+50%连接

IDM 式确认小卡片

浏览器下载被接管后弹出置顶小卡片，点击「开始下载」原地展开为进度窗口，不打扰主窗口。

OpenList 整目录下载

在 OpenList / AList 页面一键爬取当前文件夹（可含子文件夹），勾选后批量下载，保留目录结构与真实文件名，支持登录身份与加密文件夹。

递归子文件夹保留结构文件夹密码

断点续传

分段进度持久化，崩溃或重启后从断点继续；服务器不支持 Range 时自动降级为单连接。

SQLite 持久化与备份

任务和设置保存在 SQLite，旧版 JSON 自动迁移；支持导入导出，数据库损坏时自动备份并恢复。

批量管理

复选框多选，Shift 连选、Ctrl+A 全选，批量开始、暂停、重新下载与删除。

网络与代理

全局限速、并发队列，系统代理或手动 HTTP / SOCKS5 代理。

安静的界面

Bento Grid 布局，深色毛玻璃，亚克力 / 云母窗口材质；托盘、通知、剪贴板监听。

Browser

接管浏览器下载

Chrome / Edge 扩展在「另存为」弹出前拦截下载，连同 Cookie、Referer、User-Agent 一起交给 NDM；NDM 没运行时自动交还浏览器。

01

打开扩展目录

安装 NDM 后，在「设置 → 浏览器集成」打开随安装包附带的扩展目录。

02

加载扩展

访问 edge://extensions 或 chrome://extensions，开启开发者模式，「加载已解压的扩展程序」。

03

照常下载

点击下载链接即弹出确认卡片；右键链接或在 OpenList 页面也能直接交给 NDM。
